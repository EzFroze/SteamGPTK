# Установка SteamGPTK

SteamGPTK запускает Windows-игры через обычный Steam для macOS с помощью Sikarugir Wine 11 и выбранного пользователем GPTK 4. CrossOver не требуется. Проект не связан с Apple, Valve или CodeWeavers; происхождение и авторство указаны в README.

## Что нужно

- Mac с Apple Silicon и macOS 26 или новее для приложения.
- Обычный Steam в `/Applications/Steam.app`.
- Rosetta 2. Если её нет, выполни `softwareupdate --install-rosetta` и прочитай запрос Apple.
- Свой DMG **Game Porting Toolkit 4**, скачанный у Apple. Проверена версия 4.0 beta 3.
- Интернет для первой загрузки Wine и вспомогательных компонентов.

Проверка выполнена на M1 Pro с macOS 27.0.1. Совместимость зависит от игры. DirectX 8/9 автоматически работает через D9VK, включая 32-битные игры. Этот путь проверен на Half-Life 2. Совместимость с другими играми, DRM и античитами зависит от игры. В начальных настройках для проверенной конфигурации M1 трассировка лучей отключена.

## Получить приложение

Скачай `SteamGPTK.zip` из [Releases этого форка](https://github.com/EzFroze/SteamGPTK/releases), распакуй и открой `SteamGPTK.app`. Для проверки скачай также `SteamGPTK.zip.sha256` и выполни в папке с обоими файлами `shasum -a 256 -c SteamGPTK.zip.sha256`.

Приложение также можно собрать из исходников. Потребуются Command Line Tools (`xcode-select --install`) или Xcode со Swift 6.2+, а также CMake. Если Homebrew уже установлен, подойдёт `brew install cmake`.

```bash
git clone --branch codex/wine-gptk-ui --single-branch https://github.com/EzFroze/SteamGPTK.git
cd SteamGPTK
./scripts/build-free-ui.sh
open out/SteamGPTK.app
```

Для сборки используй путь к проекту без пробелов. Явно указанная ветка содержит нашу реализацию Wine/GPTK, даже если главной веткой форка пока остаётся исходный `main`.

Сборка подписана локальной подписью и не нотарифицирована Apple. Если macOS требует подтверждения, используй разрешение для этого конкретного приложения в **Системные настройки → Конфиденциальность и безопасность**. Глобально отключать Gatekeeper не нужно.

## Скачать и выбрать свой GPTK

1. Открой [Apple Developer Downloads](https://developer.apple.com/download/all/?q=game%20porting%20toolkit).
2. Войди своим Apple ID, скачай **Game Porting Toolkit 4** либо **Evaluation environment for Windows games** и ознакомься с условиями Apple.
3. Сохрани DMG в удобном месте. Распаковывать его или копировать в репозиторий не нужно.
4. Закрой Steam, Windows-игры и инструменты Wine.
5. В SteamGPTK нажми **Choose DMG…** в строке **Apple GPTK / D3DMetal** и выбери образ.
6. Дождись подготовки Wine и импорта GPTK.
7. Нажми **Install / Repair** и дождись установки интеграции.
8. Проверь готовность Wine 11, Rosetta 2, GPTK и Steam bridge, затем открой обычный Steam.

Подойдут внешний DMG GPTK и внутренний образ окружения для Windows-игр. Уже открытый в Finder образ можно использовать повторно. При замене рендерера старая версия сохраняется в резервной папке.

Пока работает Steam, установка и импорт недоступны. Повторная установка использует уже импортированный GPTK. **Import Another…** позволяет выбрать другой образ явно.

Файлы Apple не входят ни в репозиторий, ни в архив приложения. Wine загружается отдельно с проверкой контрольных сумм, а наш патч `ntdll` применяется локально. Лицензии Apple и других компонентов продолжают действовать.

## Обновление до 0.2.0 и DirectX 9

Закрой Steam и Windows-игры, открой новую версию SteamGPTK и нажми **Install / Repair**. Повторно выбирать GPTK не требуется, если он уже импортирован. Установка сохраняет Wine/GPTK, резервные копии, игровые префиксы и сохранения; настройки выбора инструмента Steam переносятся с резервной копией. При конфликте двух отдельных каталогов данных установка остановится, сохранив оба.

D9VK для DirectX 8/9 подключается автоматически. Параметр `WINEDLLPATH_D9VK`, если он был добавлен вручную, можно удалить. Настройки D3DMetal/DXMT/DXVK для DirectX 11/12 продолжают работать; явный выбор WineD3D отключает альтернативные рендереры. При первой загрузке D9VK может потребоваться время на создание графического кэша.

Служебный идентификатор `steamgptk-proton` сохраняет поддержку путей Steam Cloud. Это внутреннее имя; в интерфейсе используется SteamGPTK.

## Игры и сохранения

Windows-игры без версии для macOS используют инструмент совместимости. Нативные версии macOS сохраняют свой обычный запуск, если ты сам не выбрал Windows-инструмент в свойствах игры.

Скрипт объединяет имена профиля Wine и `steamuser`, чтобы игра и Steam обращались к одним файлам сохранений. При конфликте разных файлов запуск останавливается; одно сохранение не затирает другое автоматически.

Выгрузку и загрузку облачных сохранений выполняет сам Steam. Игра должна поддерживать Steam Cloud. Строка **Steam Cloud paths** проверяет установленную поддержку путей, а не факт синхронизации с сервером. Перед переходом на Windows выйди из игры и дождись окончания синхронизации в Steam.

## Восстановление и журналы

- Закрой Steam и используй **Install / Repair**, если повредились Wine или компоненты интеграции. Импортированный GPTK и игровые префиксы сохраняются при восстановлении.
- Обновления клиента Steam могут потребовать обновления форка. В UI есть переключатель блокировки обновлений Steam.
- Журнал приложения: `~/Library/Application Support/steamgptk/app.log`.
- Журнал игры: `steamapps/compatdata/<AppID>/steamgptk-run.log` в её библиотеке Steam.
- **Original Steam → Restore…** восстанавливает Steam без интеграции.
- **Remove SteamGPTK → Remove…** дополнительно удаляет управляемый Wine и импортированный GPTK. Игровые префиксы и сохранения остаются в библиотеке Steam.

Автообновления отключены. Новые версии нужно получать из этого форка, затем запускать **Install / Repair** при закрытом Steam.
