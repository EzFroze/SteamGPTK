# Профили игр SteamGPTK

Профиль — набор проверенных настроек запуска для конкретного Steam AppID. Профили встроены в скрипт запуска, который поставляется и в приложении, и в модуле SteamGPTK. Они применяются автоматически при запуске Windows-игры через инструмент совместимости. Отдельного экрана профилей в этой версии нет.

Профили доступны начиная с версии 0.2.2; версия 0.2.1 их ещё не содержит. Для обновления закрой Steam и Windows-игры, установи новую сборку и выполни Install / Repair. Сборка из исходников описана в README. Текущий экземпляр приложения не обновляется от редактирования исходников.

## Half-Life 2 — AppID 220, профиль hl2-v1

Проверенная конфигурация: M1 Pro, macOS 27.0.1, Sikarugir Wine 11, D9VK / DXVK-Sikarugir 3.1.1-async и KosmicKrisp 26.2.99. GPTK 4.0 beta 3 импортирован в runtime; графика D3D9 этой игры проходит через Vulkan-драйвер, а не через D3DMetal.

| Настройка | Значение |
|---|---|
| Графический backend | `CX_GRAPHICS_BACKEND=dxvk` |
| Библиотеки D3D9 | Поставляемый с runtime каталог `Frameworks/renderer/d9vk/wine` |
| Vulkan-драйвер | Поставляемый с runtime KosmicKrisp |
| VSync D3D9 | `DXVK_CONFIG="d3d9.presentInterval = 0"` |
| Объявление AVX | `ROSETTA_ADVERTISE_AVX=0` |
| Steamworks x86 | Проверенный исправленный `i386-windows/lsteamclient.dll` вместо оригинального `steamclient.dll` в префиксе HL2 |

Профиль не включает HUD, запись подробных диагностических журналов, временные повороты камеры стрелками, изменение разрешения, отключение Steam Overlay или Steam Cloud. Он также не меняет игровые сохранения и не удаляет шейдерный кэш. Ранее выставленные вручную настройки игры и Steam сохраняются.

На проверенном участке повторный проход стал плавным после восстановления моста и прогрева кэша. Это не гарантирует отсутствие фризов на новых уровнях или на других версиях runtime. Предварительная компиляция всех шейдеров игры этим профилем не выполняется.

## Ручные настройки

Оставь параметры запуска пустыми для автоматической конфигурации. Явные значения `WINEDLLPATH_D9VK`, `ROSETTA_ADVERTISE_AVX`, `DXVK_CONFIG`, Vulkan-драйвера и выбор графического backend имеют приоритет над соответствующими настройками профиля. Явный WineD3D отключает альтернативные рендереры.

Если задан `DXVK_CONFIG_FILE`, используется пользовательский файл: профиль не добавляет своё inline-значение VSync. Следи, чтобы файл существовал постоянно; сам профиль не зависит от файлов в `/tmp`.

Отключить профиль полностью для этой игры:

```text
STEAMGPTK_GAME_PROFILE=0
```

Включить только индикатор компилятора, сохранив автоматический профиль:

```text
DXVK_HUD=compiler
```

Обрабатываются `VK_DRIVER_FILES` и старое имя `VK_ICD_FILENAMES`. Для ручного выбора драйвера задавай одну из этих переменных.

## Установка и Repair

Установщик проверяет контрольную сумму поставляемого 32-битного моста, применяет проверенный патч и устанавливает его отдельно от DLL Valve. Неизвестная версия моста останавливает настройку до изменения runtime. Проверка содержимого заменяет повреждённые файлы даже при совпадающем размере.

При старте HL2 скрипт выбирает исправленный мост из отдельного каталога. Поэтому последующая проверка или повторная загрузка исходных DLL Valve не отменяет профиль. Для игр без профиля прежний выбор `steamclient.dll` сохраняется. Install / Repair не зависит от дописанных вручную строк в `runner.env`.

В журнале `steamapps/compatdata/220/steamgptk-run.log` появится строка `profile: hl2-v1`, выбранные параметры и сообщение об использовании 32-битного моста. При отключённом или отсутствующем профиле записывается `profile: none`.

## Добавление профиля

Каталог находится в `apply_game_profile` файла `dylib/feats/compat_run.sh`. Добавляй ветку только для проверенного AppID, применяй настройки как значения по умолчанию и используй пути относительно runtime. Не включай личные пути, сохранения или настройки с неизвестным эффектом.

Обнови копию скрипта в `app/Sources/SteamGPTKApp/Resources/compat_run.sh`, описание конфигурации и тесты `GameProfileTests`. Проверки должны охватывать применение по AppID, ручное переопределение, отключение профиля и повторный Repair с последующей установкой файлов Valve. Общие исправления runtime хранятся в установщике, а не в индивидуальных параметрах запуска.
