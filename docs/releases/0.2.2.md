# SteamGPTK 0.2.2

Add the first automatic game profile: **Half-Life 2 (Steam AppID 220)**. Its tested defaults select D9VK 3.1.1-async / KosmicKrisp, disable D3D9 VSync and AVX advertisement, and use the verified 32-bit Steam bridge. Launch options may be left empty. Explicit profile setting overrides take priority; `STEAMGPTK_GAME_PROFILE=0` disables the profile.

Install / Repair prepares the patched bridge separately from Valve's original downloaded DLLs. HL2 selects the separate bridge when launching, so subsequent Valve verification no longer cancels the fix. Setup also repairs equal-size bridge corruption and reports a damaged runtime i386 bridge.

Profiles preserve game graphics settings, Steam Cloud preferences, saves and shader caches. Shader compilation in new areas can still cause stutter. The HL2 configuration was tested on M1 Pro with Wine 11 and macOS 27.0.1; performance on other configurations is not established.

## Update

1. Quit Windows games, Wine tools and Steam.
2. Replace the SteamGPTK app with this version and run **Install / Repair**.
3. Clear old diagnostic launch options for HL2 to use the automatic profile, then start Steam.

This release includes 391 passing Swift tests, including profile defaults, manual overrides, loader environment forwarding and repeated repair followed by Valve installation. The app is ad-hoc signed; Apple GPTK and Wine runtime files are not included in the app archive.

## Half-Life 2: краткая инструкция

[Пошаговая установка на русском](https://github.com/EzFroze/SteamGPTK/blob/main/docs/HL2_QUICKSTART.ru.md).

1. Распакуй **SteamGPTK.zip** и перенеси приложение в **Программы**.
2. Установи Rosetta 2, если её ещё нет.
3. Скачай свой GPTK 4 DMG у Apple.
4. Закрой Steam; в SteamGPTK выбери **Choose DMG…**, дождись импорта и нажми **Install / Repair**.
5. Открой обычный Steam, выбери для HL2 инструмент **SteamGPTK (Wine / GPTK)** в свойствах совместимости и установи Windows-версию игры.
6. Оставь параметры запуска пустыми и запускай игру. Для начала подойдёт разрешение около 1920×1200; профиль применится автоматически.
