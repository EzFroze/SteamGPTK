# SteamGPTK 0.2.0

D9VK now loads automatically for DirectX 8/9 games, including 32-bit titles. Setup and repair also correct the relocated Vulkan driver paths that prevented D9VK from starting. Half-Life 2 was verified on an M1 Pro: its menu increased from approximately 7 FPS with WineD3D/OpenGL to 40 FPS with D9VK; this is a menu observation, not a gameplay benchmark.

The app, module, Swift target, logs and build artifacts now use SteamGPTK. Existing installations retain their Wine/GPTK files, backups, prefixes and saves. Steam compatibility selections are migrated with configuration backups. The internal identifier `steamgptk-proton` retains Steam Cloud path support.

## Update

1. Quit Steam, Windows games and Wine tools.
2. Replace the previous app with this version and run **Install / Repair**.
3. Keep your already imported GPTK; no new download is needed for an existing setup.
4. Start Steam. A previously added `WINEDLLPATH_D9VK` launch option is no longer required and can be removed.

The first D9VK launch can take longer while graphics caches are created. Native macOS games retain their normal route. An explicit WineD3D choice disables the alternative renderers.

The app is ad-hoc signed and is not notarized. Apple GPTK/D3DMetal and Wine runtime binaries are not included; users import their own GPTK DMG. Origin and component licenses remain in README and the bundled license notices.
