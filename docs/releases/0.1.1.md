First downloadable SteamGPTK release: launch Windows games from native macOS Steam with Sikarugir Wine 11 and your own Apple GPTK 4 download. CrossOver is not required.

### Download and setup

1. Download **SteamGPTK.zip**, extract it, and open **SteamGPTK.app**.
2. Download GPTK 4 from [Apple Developer Downloads](https://developer.apple.com/download/all/?q=game%20porting%20toolkit) under Apple's terms.
3. Quit Steam and Windows games. In SteamGPTK, use **Choose DMG…** to import your GPTK, then click **Install / Repair**.
4. Start your regular macOS Steam client.

[Installation guide](https://github.com/EzFroze/SteamGPTK/blob/steamgptk-v0.1.1/README.md) · [Инструкция на русском](https://github.com/EzFroze/SteamGPTK/blob/steamgptk-v0.1.1/docs/INSTALL.ru.md)

### Included

- Wine runtime download, installation and repair with checksum verification.
- Local GPTK import from the outer or evaluation-environment DMG.
- UI status for Wine, Rosetta, GPTK and the Steam bridge.
- Unified Wine profile paths for Steam Cloud saves; conflicting saves are preserved and reported.
- Component license notices and the exact source revision inside the app bundle.

### Requirements and limits

Apple Silicon, macOS 26+, Rosetta 2, native Steam in `/Applications/Steam.app`, and a user-supplied GPTK 4 image are required. Tested locally on M1 Pro with macOS 27.0.1 and GPTK 4.0 beta 3. Game compatibility and performance vary; 32-bit games and anti-cheat are not guaranteed. Steam handles cloud uploads/downloads for games supporting Steam Cloud.

Apple GPTK/D3DMetal and the Wine runtime are not bundled. The app is ad-hoc signed and is not notarized by Apple. If macOS blocks the first launch, use app-specific approval in **System Settings → Privacy & Security**.

Build, Swift tests, C/profile checks, shell lint, source/version validation and checksum verification must pass before publication. Download **SteamGPTK.zip.sha256** alongside the app and check it with:

```bash
shasum -a 256 -c SteamGPTK.zip.sha256
```
