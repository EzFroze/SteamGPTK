# SteamGPTK 0.2.3

Selectively bring launch, Steam integration and Metal overlay fixes from [NotProton](https://github.com/NotProtonNot/NotProton) into SteamGPTK. The free Wine/GPTK setup, user-imported Apple GPTK and automatic Half-Life 2 profile are preserved. This is a port of selected fixes, not a full upstream merge.

## Changes

- Reduce launch preparation: batch registry settings, skip unchanged settings, reuse unchanged launcher bundles and avoid repeated LaunchServices registration.
- Fix Retina DPI transitions; prefer installed Microsoft Visual C++ libraries while keeping manual DLL overrides.
- Correct Steam IDs for non-Steam shortcuts and installation helpers, suppress unwanted Steam focus activation and fix temporary path ownership.
- Fix Metal overlay pipeline/encoder ownership during completion, discard and repeated rebuilds.
- Preserve unrelated `steam.cfg` bytes and CRLF, bound downloads and report local storage failures correctly.
- Verify replacement Steam bundles copied across volumes and coordinate launch, backup, rebuild and delete with the same prefix lock.
- Handle a missing first-launch compatdata directory and release the launcher lock before displaying a terminal prefix-rebuild prompt.

Half-Life 2 still uses its automatic D9VK / KosmicKrisp profile and verified 32-bit Steam bridge. Profiles, manual overrides, Steam Cloud preferences, saves and shader cache locations are retained. This release does not promise a measured FPS increase or eliminate shader compilation stutter.

## Update / Обновление

1. Quit Windows games, Wine tools and Steam / Закрой Windows-игры, инструменты Wine и Steam.
2. Extract **SteamGPTK.zip**, replace the app in **Applications** and open it / Распакуй архив, замени приложение в **Программах** и открой его.
3. Run **Install / Repair**, then launch Steam normally / Выполни **Install / Repair**, затем запусти обычный Steam.
4. For HL2, use **SteamGPTK (Wine / GPTK)** and leave launch options empty to use the automatic profile / Для HL2 выбери **SteamGPTK (Wine / GPTK)** и оставь параметры запуска пустыми.

New users: [краткая инструкция для HL2](https://github.com/EzFroze/SteamGPTK/blob/main/docs/HL2_QUICKSTART.ru.md). Download your own GPTK 4 DMG from Apple; Apple GPTK and the Wine runtime are not included in the app archive. The app is ad-hoc signed and is not notarized.

## Verification and known limitation

Local verification covers 408 Swift tests, 10 launch-helper tests, native/shell checks, 8 overlay tests across arm64/x86_64 and relocated app signature/resource checks. The development build was also tested locally with HL2.

A deferred edge case remains: if the bundle helper is unavailable or reports a read error, its shell fallback can miss a nested directory permission error and keep an unreadable Resources directory. Normal bundle comparison, replacement and rollback have regression coverage. [Port details and attribution](https://github.com/EzFroze/SteamGPTK/blob/main/docs/UPSTREAM_SYNC_2026-10-29.md).
