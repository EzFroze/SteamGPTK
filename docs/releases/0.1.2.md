Fixes the startup crash in the GitHub-built SteamGPTK 0.1.1 app.

The native SwiftPM resource accessor could find resources in the GitHub runner's build directory while tests ran, but failed after the downloaded app was moved to another machine. SteamGPTK now loads its resource bundle directly from `Contents/Resources`. CI checks a relocated app and repeats the check after extracting the shipping ZIP, without opening the UI or modifying Steam.

### Install

1. Download **SteamGPTK.zip**, extract it, and replace the previous **SteamGPTK.app** with this version.
2. Open SteamGPTK. Your existing Wine runtime, imported GPTK and game prefixes do not need to be removed.
3. For a fresh setup, quit Steam, use **Choose DMG…** to import your GPTK 4 image, then click **Install / Repair**.

[Installation guide](https://github.com/EzFroze/SteamGPTK/blob/steamgptk-v0.1.2/README.md) · [Инструкция на русском](https://github.com/EzFroze/SteamGPTK/blob/steamgptk-v0.1.2/docs/INSTALL.ru.md)

Requires Apple Silicon, macOS 26+, Rosetta 2, native Steam and a user-supplied GPTK 4 DMG. Apple GPTK/D3DMetal and the Wine runtime are not bundled. The app is ad-hoc signed, not notarized; use app-specific approval in **System Settings → Privacy & Security** if required by macOS.

Download **SteamGPTK.zip.sha256** alongside the app and verify the download with:

```bash
shasum -a 256 -c SteamGPTK.zip.sha256
```
